# 桌面界面改造

## 设计方向

在现有 Tauri + React 客户端上统一界面，不迁移路由器，保留既有配置格式与主窗口命令契约。状态栏快捷面板增加专用汇总与操作接口，复用现有客户端接管逻辑。保留系统原生窗口标题栏，不绘制假的 macOS 窗口按钮。

参考 [Magpie 的供应商管理](https://usemagpie.ai/) 的简洁列表和连接状态表达，以及 [CC Switch](https://github.com/farion1231/cc-switch) 的导航分组、客户端分类和就近操作。只借鉴布局思路，品牌素材沿用 XXSwitch 自有资源。

参照 Apple HIG 的 [macOS 设计](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars)、[工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars) 与 [布局](https://developer.apple.com/design/human-interface-guidelines/layout)：使用系统字体、稳定的侧栏、紧凑的上下文工具栏、适度的信息密度和可随窗口调整的内容布局。

视觉采用中性灰底色、白色内容表面和原有绿色操作强调（主色 `#0f8f68`、深色强调 `#087452`），页面模块统一使用细边框、不加阴影。Radix 使用 Jade 色系，并将主要强调色映射到同一套语义变量；按钮、选中状态、开关、复选框、焦点提示和图表主色同步。浅色、深色和跟随系统共用一套语义颜色；外观选择横向排列且不显示图标间分隔线，偏好只保存在 WebView / 浏览器的本地存储中。

字体与按钮参考 Magpie 官网的[供应商列表](https://usemagpie.ai/img/providers-light.png)和[代理面板](https://usemagpie.ai/img/panel-light.png)，采用紧凑字号和克制的控件边框。以下尺寸是 XXSwitch 的统一规则：正文、表单标签、输入框、下拉菜单与普通按钮均为 13px / 20px，说明文字为 12px / 18px，元信息为 11px，模块标题为 15px。主次按钮和分段选择统一高 32px，小按钮与图标按钮高 28px，圆角 6px；表单输入保留 36px 高度。主按钮通过颜色强调，所有操作按钮保持无阴影，分段选择使用同一底色、选中边框与无分隔线样式。

## 组件基础

- 保留 React 19，统一采用 [Radix Themes](https://www.radix-ui.com/themes/docs/overview/getting-started)。`Theme` 与现有浅色 / 深色 / 系统偏好同步，弹出菜单和弹窗继承相同主题。
- 按钮、输入框、文本域、下拉菜单、复选框、开关、分段选择、Tabs、卡片、徽标、提示气泡、Dialog 和 Alert Dialog 均使用 Radix 组件。图表与业务布局仍由应用组合，不引入其他组件库。
- 图标统一使用 [Lucide React](https://lucide.dev/guide/react)，不再混用手绘 SVG 与 CSS 图形。
- `src/components/ui.tsx` 封装 Radix 组件及空状态、复制等业务组合。选择控件在边界编码值，保留空值筛选和数字值；复选框原生支持部分选中状态，导入确认与删除确认不再使用浏览器原生弹框。
- `src/styles/tokens.css` 集中定义颜色、圆角、阴影、字体和间距；`src/App.css` 组织页面布局与组件状态，替换原有多层重复覆盖样式。
- `src/types.ts` 保存原有数据契约，供正式界面和模拟后端共同使用。
- 总览与使用统计共用 `UsageTrendChart`，参考 [Magpie 的用量图表](https://github.com/yetone/magpie/blob/main/internal/gui/assets/app.css) 的轻网格、细线和低强度填色。绘图区按容器实际宽度生成坐标，字体不随 SVG 缩放；纵轴使用万 / 亿等紧凑单位并为标签留足空间，横轴随可用宽度减少刻度。密集序列仅在聚焦时强调数据点，单点不绘制面积和趋势连线；Radix Tooltip 保留完整 Token 与请求数，并支持键盘聚焦。真实数据分桶、筛选及统计逻辑保持原样。
- 总览模型用量和统计调用分布共用 `UsageName`：融合模型显示“模型名（供应商）”，不把编码后的路由 ID 当作主标签；移除的供应商只保留模型名，完整原始标识仍可通过 Radix Tooltip 或键盘聚焦查看。名称单行省略、计数不收缩，提示内容可换行，避免长名称挤出卡片。`modelLabels.ts` 只处理显示，分组键、计数、筛选与原始日志不变。

## 功能对应

| 页面     | 保留的能力                                                                                                    | 界面调整                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 总览     | 时间范围、Token / 请求趋势、供应商状态、模型用量、请求质量                                                    | 四个指标卡、明确的图表层级；环图和模型进度条使用实际比例；无调用时展示空状态           |
| 路由     | Codex / Claude / Pi 接管、默认模型、WebSocket、压缩、上下文、子代理、保存与撤销、未保存保护                   | 分组配置卡、固定工具栏操作；路径和地址提供复制反馈；读取已有配置变更列表               |
| 供应商   | 分类、新增、编辑、删除、启停、拖拽优先级、协议、Fast / Ultrafast、故障策略、模型、映射、余额、模型测试        | 统一列表与编辑抽屉；补齐本地搜索和状态筛选；支持方向键排序，筛选期间禁用排序以避免误排 |
| 使用统计 | 时间 / 供应商 / 模型筛选、Token 指标、趋势、用量明细                                                          | 与总览共用指标与时间控件；调用分布可以按模型或供应商切换                               |
| 请求记录 | 搜索、状态 / 模型 / 供应商筛选、自动刷新、分页、CSV、Debug JSON、请求详情和 Debug 视图                        | 表格独立横向滚动，长路由结果可以换行；详情统一为分组弹窗                               |
| Skills   | 扫描路径、共享写入路径、发现、共享、共享范围、同名处理、删除与暴露健康状态                                    | 统一路径表单、共享卡片、范围选择和空状态                                               |
| 设置     | WebDAV 连接 / 预览 / 上传 / 下载 / 自动上传、本地代理与超时、Slow 模式、故障停用、Debug、自启、能力目录与更新 | 统一分组设置表单，外观选项可在窄窗口中从设置页访问                                     |

原有尚未实现的装饰性控件（例如供应商页“自动检查”“检查全部”）不再呈现为可执行功能。配置路径旁原本未连接后端的“打开文件”改为实际可用的“复制”。状态栏快捷面板的窗口能力仅开放事件监听，业务操作由限制调用窗口的原生命令处理，详见[状态栏设计](tray-panel.md)。

## 与日常使用隔离

```bash
pnpm dev:ui
```

预览仅在 `127.0.0.1:1422` 提供浏览器页面，与原有开发端口 `1420` 和本地网关端口分开。它不启动 Tauri / Rust，不触碰已安装的客户端，也不读取现有供应商、API Key、Skills、日志或配置。

`src/preview/mockBackend.ts` 使用 Tauri 官方 `mockIPC` 接管预览中的命令；数据为合成示例，所有变更只存在当前页面内存中。供应商保存、启停、排序、模型测试、日志筛选、分页、Debug、Skills 和 WebDAV 操作均在内存中模拟。预览中的 WebDAV 表单不会连接远端，应用安装和打开真实文件等未模拟操作明确拒绝执行。

入口同时检查开发模式与 `ui-preview` 模式，并拒绝在原生 Tauri 环境中安装模拟后端。正式构建会移除这一分支及模拟模块。

- 常规数据：`http://127.0.0.1:1422/`
- 空数据：`http://127.0.0.1:1422/?scenario=empty`
- 网关未运行：`http://127.0.0.1:1422/?scenario=offline`
- 网页导入确认：`http://127.0.0.1:1422/?scenario=import`
- 大数值趋势：`http://127.0.0.1:1422/?scenario=chart-large`，两个月的十亿级合成用量，用于检查刻度、稀疏序列与提示位置。
- 长名称：`http://127.0.0.1:1422/?scenario=long-names`，合成长路由前缀、同名模型的两条线路、长模型名与长供应商名，用于验证标签、省略、提示与原始统计身份。
- 状态栏快捷面板：`http://127.0.0.1:1422/?view=tray`，可叠加 `scenario=empty` / `scenario=offline`；开关、模型、显示偏好和退出仅修改内存状态。

## 验证

```bash
pnpm test:ui
```

该命令执行 TypeScript 检查、生产构建和 `scripts/ui-preview.test.mjs`，验证模拟命令、筛选、分页、Token 一致性、状态变更、共享操作、刷新周期保存回读、导入确认 / 取消 / 防重复处理、重置和空 / 离线场景，并禁止测试中的网络请求。图表检查覆盖十亿级刻度、200–1100px 绘图区、单点与空序列，以及模拟的月度用量一致性。生产资源检查确保 JavaScript 不含预览 IPC、合成数据或大数值调试场景。

浏览器交互检查覆盖主要页面、供应商筛选与编辑、模型测试、路由草稿保护、请求详情 / Debug、主题和空数据状态。Radix 组件回归覆盖空值筛选、数字选项保存后重新打开、弹窗内菜单、键盘导航、部分选中 / 全选、Debug Tabs、删除确认 / 取消、导入确认 / 取消和深色菜单主题继承。macOS WebKit 的真实 Radix 组件渲染检查确认，浅色与深色的输入框、下拉框均为 36px，空值与数字选项、部分选中和禁用状态正确。设置页与侧栏的外观选项保持横排，主题选中状态同步。

已完成 Apple Silicon / Intel 通用生产编译、应用签名校验、DMG 校验与只读挂载检查。正式客户端继续调用真实后端，状态栏面板调用专用汇总与单项操作接口；生产资源不含模拟 IPC 或合成数据。本地验证包采用临时签名，未进行 Apple 公证。开发与打包没有自动安装、重启或替换正在使用的客户端，真实上游连接未在本次开发中执行回归。

GitLab 的 `frontend:build` 运行 `pnpm test:ui`，保留生产资源构建产物，并在 MR 中检查预览隔离。
